Welcome to Eyes On Me's documentation!
======================================

This project, "Eyes On Me", is a DepthAI-based perception system designed for
real-time object detection, spatial localization, and orientation tracking.
It integrates various sensors and models to provide a comprehensive understanding
of the scene.

This documentation provides an overview of the system architecture, individual
module functionalities, and the API reference for developers.
